## Запуск

Node.js >=22.13.0, npm. Установите зависимости: `npm ci`. Разработка: `npm run dev`. Сборка напрямую: `npx vinext build`. Оригинальный `npm run build` использует bash и GNU timeout (Linux; на macOS требуется GNU coreutils).

## Структура

- app/page.tsx — страница и тексты.
- app/globals.css — оформление и адаптивность.
- public/assets — изображения.
- package-lock.json — зафиксированные зависимости.
- README.md — оригинальная техническая документация.

Проект использует React, Vinext/Vite и Cloudflare Worker. Это экспорт исходников существующего сайта, а не адаптация под Vercel.
