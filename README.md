# Дизайн без воды с помощью AI

Актуальная версия лендинга курса, перенесённая из https://design-bez-vody.tinapo.chatgpt.site (версия 40).

## Запуск

Node.js 22.13+

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
```

Результат: `dist/`. Для Vercel настройки находятся в `vercel.json`.

Контент и компоненты: `src/App.tsx`. Стили: `src/style.css`. Изображения: `public/assets/`.
